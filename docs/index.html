Mỗi project là một data package độc lập

Thêm domain mới mà không trộn dữ liệu hoặc làm hỏng project hiện có. Metadata luôn đi cùng bảng dữ liệu.

  • Mỗi bảng có grain và khóa rõ ràng.
  • Fact lớn được partition theo trường truy vấn phổ biến.
  • Mart có thể tái tạo từ fact và dimension.
  • Dashboard chỉ đọc asset tổng hợp đã kiểm tra.
